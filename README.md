# X4 Station Planner

Live: https://skullwarriorsergio.github.io/x4-station-planner/

A production-chain planner for **X4: Foundations 9.00**: seven stations feeding one shipyard, with live per-hour balances, energy per station, mining demand, cross-station flows and the new 9.00 **Allographyne** chain (calculator, raw Kha'ak scrap fields, Nividium belts).

- Works in any browser and can be installed as a home-screen app. It also works offline once loaded.
- Phones get a mobile layout: one station per screen, swipe between stations, big +/− steppers, collapsible sections. Switch with *View* (Auto / Mobile / Desktop).
- **Nopileos Kingpin mod** switch: off = vanilla sectors with their real sunlight; on = S1–S4 and S6 in Nopileos' Fortune II at the mod's 250 % sun (one big sector with a long local highway, so no trader crosses a gate). Each station also has 2–3 location options; solar module counts follow the sector.
- Your layout is saved in your browser. Use Export / Import to move it between devices.

Recipes and prices come from the X4 9.00 game files (base + DLC `wares.xml`, `mapdefaults.xml`, `regionyields.xml`). X4: Foundations and its data belong to Egosoft.
